# Deprecated atoms

Review unsupported atoms.

## Topics

### Movie atoms

[`Movie profile atom ('prfl')`](https://developer.apple.com/documentation/quicktime-file-format/Movie_profile_atom)

An atom that summarizes the features and complexity of a movie.

[`Track profile atom ('prfl')`](https://developer.apple.com/documentation/quicktime-file-format/Track_profile_atom)

A child atom of movie atoms or track atoms.

[Appendix F: Profile atom guidelines](https://developer.apple.com/documentation/QuickTime-File-Format/Appendix_F_Profile_atom_guidelines)

Summarize profile information about a QuickTime movie so readers can easily determine features and complexity.

### Media data atom types

[Sprite media](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_media)

Sprite media is used to store character-based animation data in QuickTime movies.

[Sprite track properties](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_track_properties)

Define properties that apply to an entire sprite track.

[Sprite track media format](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_track_media_format)

A media format for that stores sprite track information in atoms.

[Sprite media atom and data types](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_media_atom_and_data_types)

Atoms that represent sprite media and data types.

[Sprite button behaviors](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_button_behaviors)

Specify simple button behaviors for sprites in a sprite track.

[QT atom container description key](https://developer.apple.com/documentation/QuickTime-File-Format/QT_atom_container_description_key)

Build QT atom container-based data structures.

[Sprite media handler track properties QT atom container format](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_media_handler_track_properties_QT_atom_container_format)

Set sprite media handler track properties in a QT atom container.

[Sprite media handler sample QT atom container formats](https://developer.apple.com/documentation/QuickTime-File-Format/Sprite_media_handler_sample_QT_atom_container_formats)

Set sprite media handlers in QT atom containers.

[Wired action grammar](https://developer.apple.com/documentation/QuickTime-File-Format/Wired_action_grammar)

Embed QT event handlers in their media samples.

[Tween media](https://developer.apple.com/documentation/QuickTime-File-Format/Tween_media)

Store pairs of values to be interpolated between in QuickTime movies using tween media.

[3D media](https://developer.apple.com/documentation/QuickTime-File-Format/3D_media)

Store 3D image data in a base media in QuickTime movies.

[VR media](https://developer.apple.com/documentation/QuickTime-File-Format/VR_media)

Atoms that describe the QuickTime VR world.

[Node parent atom](https://developer.apple.com/documentation/QuickTime-File-Format/Node_parent_atom)

An atom that is the parent of one or more node ID atoms.

[`Node location atom structure ('nloc')`](https://developer.apple.com/documentation/quicktime-file-format/Node_location_atom_structure)

An atom that describes the type of a node and its location.

[Custom cursor atom](https://developer.apple.com/documentation/QuickTime-File-Format/Custom_cursor_atom)

An atom you use to replace the default cursors used by QuickTime VR.

[Node information atom container](https://developer.apple.com/documentation/QuickTime-File-Format/Node_information_atom_container)

An atom container that includes general information about the node such as the node's type, ID, and name.

[URL hot spot atom](https://developer.apple.com/documentation/QuickTime-File-Format/URL_hot_spot_atom)

An atom that contains a URL string for a web location.

[Support for wired actions](https://developer.apple.com/documentation/QuickTime-File-Format/Support_for_wired_actions)

Support wired actions in a QuickTime VR file.

[QuickTime VR file format](https://developer.apple.com/documentation/QuickTime-File-Format/QuickTime_VR_file_format)

A file format used to store a QuickTime VR movie on disk.

[QTVR track](https://developer.apple.com/documentation/QuickTime-File-Format/QTVR_track)

A track that maintains a list of all the nodes in a movie.

[Panorama tracks](https://developer.apple.com/documentation/QuickTime-File-Format/Panorama_tracks)

A track that contains information about the panoramic nodes in a scene.

[Cubic panoramas](https://developer.apple.com/documentation/QuickTime-File-Format/Cubic_panoramas)

A panorama represented by six faces of a cube, so the viewer can see all the way up and down.

[Panorama tracks in cubic nodes](https://developer.apple.com/documentation/QuickTime-File-Format/Panorama_tracks_in_cubic_nodes)

Specify special values in the pano sample data atom to provide compatibility back to QuickTime VR 2.2.

[Nonstandard cubes](https://developer.apple.com/documentation/QuickTime-File-Format/Nonstandard_cubes)

An atom you add to the pano sample atom container to specify cubes other than six square faces.

[Hot spot image tracks](https://developer.apple.com/documentation/QuickTime-File-Format/Hot_spot_image_tracks)

Identify hot spots in a panorama with a hot spot image track.

[Object tracks](https://developer.apple.com/documentation/QuickTime-File-Format/Object_tracks)

A track that contains information about the object nodes in a scene.

[Track references for object tracks](https://developer.apple.com/documentation/QuickTime-File-Format/Track_references_for_object_tracks)

Specify track references for object tracks.

[QuickTime image file format](https://developer.apple.com/documentation/QuickTime-File-Format/Appendix_A_QuickTime_image_file_format)

Store QuickTime-compressed still images.

[Summary of VR World and node atom types](https://developer.apple.com/documentation/QuickTime-File-Format/Appendix_E_Summary_of_VR_World_and_node_atom_types)
