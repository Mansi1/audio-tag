# Basic QuickTime data types

Express values in QuickTime files with common data types.

## Topics

### Languages

[Language code values](https://developer.apple.com/documentation/QuickTime-File-Format/Language_code_values)

Indicate the language associated with a particular object using language codes.

### Dates and times

[Calendar date and time values](https://developer.apple.com/documentation/QuickTime-File-Format/Calendar_date_and_time_values)

QuickTime movies store date and time information in Macintosh date format.

### Graphics and colors

[Matrices](https://developer.apple.com/documentation/QuickTime-File-Format/Matrices)

QuickTime files use matrices to describe spatial information about many objects, such as tracks within a movie.

[Graphics modes](https://developer.apple.com/documentation/QuickTime-File-Format/Graphics_modes)

QuickTime files use graphics modes to describe how one video or graphics layer should be combined with the layers beneath it.

[RGB colors](https://developer.apple.com/documentation/QuickTime-File-Format/RGB_colors)

Colors stored as three consecutive unsigned 16-bit integers in the following order: red, green, blue.

[Balance](https://developer.apple.com/documentation/QuickTime-File-Format/Balance)

Represent balance values with 16-bit fixed-point numbers.
