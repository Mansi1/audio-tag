# audio-tag website

The overview with the playground, the docs and the 404 page of
[audio-tag](https://mansi1.github.io/audio-tag/), built with
[defuss](https://github.com/kyr0/defuss) (`defuss-ssg`) and
[defuss-shadcn](https://github.com/kyr0/defuss-shadcn) into `dist/`.

## Build

It needs bun and Node 22 or newer, and the library built first, since the site reads `../dist/`:

```sh
npm run build            # in the repository root: the library, with dist/build-info.json
cd website
bun install
bun run build            # → website/dist/
```

From the root, `npm run site` runs the website build, and `npm run serve` builds both and serves the site
at `http://localhost:5173/`. `make e2e` builds and drives it in Chromium.

## Commands

| Command | What it does |
|---|---|
| `bun run build` | Renders the pages into `dist/` (checks for Node 22 first) |
| `bun run dev` | The defuss-ssg dev server with live reload; stop it before a build, since both use `.ssg-temp/` ([kyr0/defuss#64](https://github.com/kyr0/defuss/issues/64)) |
| `bun run test` | `bun test lib`: the byte map on the sample files in `../input/` |
| `bun run lint` | `oxlint --deny-warnings` on the components, `lib/` and `config.ts` |
| `node scripts/og-image.mjs` | Renders the link preview `assets/og.jpg` (1200 × 630) from the README banner; run it after changing the banner |

## Where things are

| Path | Contents |
|---|---|
| `pages/*.mdx` | One per page: front matter (title, description) and one page component |
| `lib/pages/*.tsx` | The pages: home, docs, not-found (rendered at build time only) |
| `lib/*.tsx` | Head, header, footer and the docs tables, rendered at build time only |
| `components/*.tsx` | The interactive parts, hydrated in the browser: the playground and the filterable tables |
| `lib/code-block.tsx`, `lib/highlight.ts` | Code examples with syntax colors (at build time) and a copy button (`assets/site.js`) |
| `lib/byte-map.ts` | Which byte range of a file is what; the playground's byte map draws it |
| `lib/ui.ts` | The defuss-shadcn components the site loads |
| `data/support.json` | Frames, field mapping and genres, generated by `npm run docs:matrix` |
| `assets/` | Theme (the README palette), layout CSS, `site.js`, the icon and the link preview `og.jpg` |
| `lib/site.ts` | The published address, for the link preview tags and the 404 page |
| `lib/diagram.tsx` | The README diagrams (`../.github/readme/*.svg`) as SVG elements that follow the theme |
| `config.ts` | The defuss-ssg plugins and the alias to the library build |

See [`ARCH.md`](ARCH.md) for why it is built this way.
